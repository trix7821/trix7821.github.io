🛠️ Interactive Guides

Step-by-step instructions to get the most out of TrixOS. Click on each step to expand.

📥 How to Install TrixOS

1 Download the installer

Go to the Download page and click the Download Installer button. The file TrixOS_Installer.exe will be saved to your computer.

2 Run as administrator

Right-click the installer and select "Run as administrator". This is required to apply system tweaks.

3 Choose components

Select which components you want to install: GUI, CLI, or Cloud. We recommend installing all three.

4 Installation progress

Wait while the installer copies files. The process takes about 30 seconds. You can choose to launch TrixOS immediately after installation.

5 Installed files

After installation, you'll find three executables in the installation folder: TrixOS_Gui.exe, TrixOS_CLI.exe, and TrixOS_Cloud.exe.

6 Launch TrixOS

Double-click TrixOS_Gui.exe to launch the graphical interface. You can also run CLI or Cloud versions from the same folder.

⚡ How to Apply Tweaks

1 Open the Tweaks tab

In the main window, click on the "Tweaks" tab. You'll see a list of all available tweaks grouped by category.

2 Select tweaks

Check the boxes next to the tweaks you want to apply. Hover over any tweak to see a description of what it does.

3 Apply and restore

Click "Apply Selected" to apply the tweaks. A system restore point will be created automatically. If something goes wrong, use "Revert Selected" or restore from the restore point.
