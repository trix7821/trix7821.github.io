TrixOS — Windows Optimization Tool for Windows 10 & 11

One‑click system tweaks to boost performance, disable telemetry, remove bloatware, and take full control of your Windows experience. No technical skills required.

TrixOS is a free and open‑source utility that applies system tweaks to improve your PC's speed, privacy, and stability. It's designed for both beginners and advanced users.

🔒 Is it safe? Yes. TrixOS creates a System Restore Point before applying changes. If something goes wrong, simply restore your system to the previous state.

What TrixOS can do

  • Disable Windows Telemetry & Data Collection
  • Remove pre‑installed bloatware apps
  • Optimize network settings for lower ping
  • Disable Cortana and background apps
  • Turn off Windows Defender (optional)
  • Stop automatic Windows Updates
  • Speed up boot time and shutdown
  • Disable Xbox Game Bar and Game DVR
  • Optimize power settings for maximum performance
  • Clean up temporary files and junk
  • Disable animations and visual effects
  • Improve SSD/HDD performance
  • Disable Microsoft Edge startup boost
