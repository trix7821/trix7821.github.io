TrixOS v1.0.3 Released – Bugfixes and Improvements

August 13, 2026

We're happy to announce the release of TrixOS v1.0.3 – a bugfix update that addresses several issues and improves the overall experience.

What's new

  • Fixed installer – now installs the correct version (v1.0.3). Installer filename now includes version: TrixOS_Installer_v1.0.3.exe.
  • Updates are now notification-only – the app shows a notification when a new version is available, but does not download it automatically. You decide when to update.
  • Improved tweak status detection – all applied tweaks are now correctly detected on startup (checks every registry key).
  • Added timestamps to logs – each log message now includes [HH:MM:SS] for better tracking (GUI & Cloud).
  • History auto-refresh – History tab updates automatically after applying/reverting tweaks (no need to click Refresh).
  • Updated About section – removed personal Telegram, added support bot @TrixOS_Support_bot, kept Telegram channel @thetrix21.
  • Installer version in filename – prevents confusion with previous versions.

Download the new version from the Download page or GitHub Releases.

Enjoy a cleaner, faster Windows! 🚀
