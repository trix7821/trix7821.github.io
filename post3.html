How I Built TrixOS and Why I Made It Free

August 12, 2026

I’m not a professional developer. I’m just a guy who got tired of reinstalling Windows and spending an hour disabling telemetry, deleting Candy Crush, and tweaking registry settings every single time.

One day I thought: why not automate this? So I wrote a small PowerShell script that did everything for me. It worked. I used it, my friends used it, and they said: “Make it look like a normal program.”

That’s how TrixOS started.

At first, it was just a simple form with checkboxes. Then I added more tweaks. Then I realized not everyone wants a GUI — some people prefer command line. So I split it into three versions: GUI, Cloud, and CLI. Each one does the same thing, just in a different way.

The hardest part wasn’t the code. It was making sure nothing breaks. Every tweak changes something in the registry or system settings. If you mess up, you can kill Windows. So I added a system restore point before every change. If something goes wrong — just roll back and try again.

Of course, I didn’t do everything perfectly. The installer has a bug that I’m fixing right now. v1.0.3 is on the way. That’s how it goes — you release, people test, you fix, repeat.

Why open-source? Simple: I want people to trust me. If you can read the code, you know there’s no spyware or hidden garbage. Also, I want help. If someone has a good idea or finds a bug, they can contribute. It’s a community thing.

And yes, it’s free. Completely free. No ads, no subscriptions, no premium plans hidden behind a paywall.

But here’s the truth: I want to turn this into something bigger. Once TrixOS has a solid user base — let’s say a few hundred people who actually use it and leave feedback — I plan to launch a Pro version with extra features. The free version will stay free forever. The Pro version will be for those who want more.

So if you’re reading this and you tried TrixOS — thank you. Seriously. Every download, every comment, every bug report helps me make it better.

If you want to help:

  • Download it from the download page
  • Leave a review
  • Report a bug on GitHub
  • Join the team — apply here

I built TrixOS because I needed it. But now I’m building it because other people need it too.

That’s the whole story.
